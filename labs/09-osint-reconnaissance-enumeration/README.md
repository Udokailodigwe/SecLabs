# Lab 09 — OSINT, reconnaissance and enumeration

**Objective:** Discover and correlate publicly indexed infrastructure information.

**Environment:** Kali Linux, Windows host, theHarvester, Recon-ng, Shodan, Censys and curl.

**Results:** 16 and 164 reported host records in separate enumeration outputs; 883 Shodan search matches; no indexed services returned for the personal public IP lookup.
