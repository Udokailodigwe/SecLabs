# Lab 14 — Network attack simulation

**Objective:** Evaluate network interception, Layer 2 attack behavior and phishing-related connectivity in a controlled lab.

**Environment:** Kali Linux, Ubuntu, Windows Server 2022 and Hyper-V.

**Tools:** arpspoof, urlsnarf, macof, Wireshark, SET, Netcat and PowerShell.

**Result:** HTTP traffic captured and TCP connectivity verified. MAC flooding traffic generated; phishing delivery and switch table exhaustion not confirmed.
